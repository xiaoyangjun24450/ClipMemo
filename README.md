### clip-analyze（AI 分析）

- 描述：对单条剪贴内容进行 AI 分析，智能识别类型与数据来源，生成描述与检索关键词
- 调用方：`api.analyzeClip(clip)`（`utils/api.js`）
- 输入
    - `content`：剪贴文本内容
    - `types`：（可选）本地类型库，传入所有可选类型列表，供 AI 优先匹配
- 输出
    - `aiType`：AI 识别的类型 —— 优先从传入的 `types` 中选择一个最匹配的；若都不合适，可自定义一个新类型
    - `dataSource`：推测的数据来源（如 微信、网页、邮件、代码编辑器 等）
    - `description`：50 字以内的内容摘要描述
    - `keywords`：用于检索的关键词数组，不超过10个词
- 触发时机：新内容通知条 → "AI 分析" 按钮

## 事件设计

- 当APP在前台的时候，获取一次剪切板内容，并显示在新内容通知条上。新内容通知条可选择：
    - 查看，会进入分析面板（半屏），你可以选择：
        - 不存，则不显示新内容通知条
        - 仅保存到本地，去重
        - AI分析，生成检索关键词
    - 忽略，则不显示新内容通知条
