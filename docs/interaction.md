# ClipMemo 交互设计

## 交互原则
不选择则不打扰、本地操作 0 延迟、用户掌控数据去留。

---

## Page: 首页 (index)

### 页面结构
  顶部固定：搜索栏（占位"搜索剪贴内容..."）+ 类型筛选图标
  下方主体：无限滚动时间线列表
  列表空态：图标 + "还没有内容，复制后切回来试试"

### 卡片: 内容条目
  ┌─────────────────────────┐
  │ [类型图标]  标签1 标签2 标签3       │
  │  内容预览最多两行超出省略...        │
  │  3分钟前 · 已复制12次               │
  │  [复制]               [···]        │
  └─────────────────────────┘
  点击卡片 → 展开
  点击[复制] → 写回剪贴板 + toast"已复制"
  点击[···] → 底部弹出操作菜单：删除 / 编辑标签

### 卡片: 新内容通知条（非模态，从顶部滑入）
  ┌─────────────────────────┐
  │ 检测到："前20字预览..."  [查看] [忽略]│
  └─────────────────────────┘
  点击[忽略] → 消失
  点击[查看] → 展开半屏分析面板（见下方）

---

## Page: 分析面板（半屏，首页上方弹出）

### 卡片: 本地识别结果
  ┌─────────────────────────┐
  │ 完整内容（可滚动，长内容折叠）        │
  │ 识别类型：🔗 网页链接                │
  │ [存入并AI分析] [仅保存到本地] [不存]  │
  └─────────────────────────┘

### 卡片: AI分析结果（选择"存入并AI分析"后出现）
  ┌─────────────────────────┐
  │ 分析中...（3秒骨架屏）              │
  │ ↓                                    │
  │ 最终类型：📕 小红书笔记               │
  │ 标签：[护肤×] [成分×] [避坑×] [+添加] │
  │ 摘要：本文介绍了2026年...展开全文编辑  │
  │ [确认保存]          [返回修改]        │
  └─────────────────────────┘
  保存成功 → toast + 自动插入列表顶部

## Page: 详情页 (detail)

### 页面结构
  顶部：返回箭头 + 标题（取前20字/AI生成标题）
  中间：内容区 + 信息区
  底部固定：大按钮"复制到剪贴板"

### 卡片: 内容区
  ┌─────────────────────────┐
  │ 类型标签（大号彩色）                 │
  │ 标签1  标签2  标签3  [+编辑]         │
  │                                      │
  │ 完整内容展示（长按可局部复制）        │
  │ [全文复制]                           │
  └─────────────────────────┘

### 卡片: 链接摘要区（仅链接类内容显示）
  ┌─────────────────────────┐
  │ 📄 AI摘要                             │
  │ 这篇文章主要讲了...                   │
  │ [查看原文链接]                        │
  └─────────────────────────┘

  │ 已复制 N 次 · 首次保存 YYYY-MM-DD     │

  └─────────────────────────┘

## Page: 设置页 (settings)

### 卡片: 设置项（无分割线，仅四项）
  ┌─────────────────────────┐
  │ 剪贴板监控          [开关 ●]       │
  │ 自动弹出确认        [开关 ●]       │
  │ 导出全部数据        [按钮 >]       │
  │ 清空所有数据        [按钮 >]       │
  └─────────────────────────┘
  清空需二次确认弹窗。

---

## 通用: 搜索状态

  点击搜索栏 → 键盘弹起 → 显示搜索历史+热门标签
  输入中 → 200ms防抖 → 本地即时匹配 → 结果少于5条自动走后端语义搜索
  结果项高亮匹配关键词
  无结果：图标 + "没找到，试试换个说法？" + 推荐标签
  搜索栏 × → 清除 → 恢复默认时间线

---

## 通用: 异常状态

  首次无数据：图标 + "去别处复制一段试试吧"
  搜索无结果：图标 + "没找到" + 标签推荐
  网络异常：顶部红色提示条
  权限被拒：全屏引导去设置
